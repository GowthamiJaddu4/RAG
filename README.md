# RAG
RAG learning repository

This was the basic pipeline you can easily understand how rag works

Document
   ↓
Split into chunks
   ↓
Create embeddings for chunks
   ↓
Store embeddings
   ↓
User question
   ↓
Create embedding for question
   ↓
Compare similarity
   ↓
Retrieve relevant chunks
   ↓
Give chunks + question to LLM
   ↓
Final answer
